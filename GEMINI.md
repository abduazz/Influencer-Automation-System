# Project Rules

См. полный список правил в [AGENTS.md](file:///Users/mac/Documents/Influencer-Automation-System/AGENTS.md).

## 🚨 КРИТИЧЕСКОЕ ПРАВИЛО: ПОЛНЫЙ ЗАПРЕТ НА ВЫПОЛНЕНИЕ ТЕСТОВ (`php artisan test`)
- **НИКОГДА** не выполнять `php artisan test`, `vendor/bin/phpunit`, `pest` или их вариации.
- Запрещено запускать тесты в консоли при любых обстоятельствах (проверка кода, отладка, валидация).
- Проверка тестов разрешена **только статически** через просмотр кода.

## 🛑 ПРАВИЛО: ЗАПРЕТ НА САМОСТОЯТЕЛЬНЫЕ КОММИТЫ (`git commit`)
- **НИКОГДА** самостоятельно не делать коммиты (`git commit`, `git merge`, `git push` и т.д.).
- Делать коммит разрешено **ТОЛЬКО** по прямому и явному запросу пользователя.
