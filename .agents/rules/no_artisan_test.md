# Запрет запуска тестов (No Artisan Test)

## 🚨 Строгое ограничение выполнения команд

**Категорически запрещено выполнять команду `php artisan test` и любые её вариации.**

### Запрещено:
- `php artisan test` (включая любые флаги, такие как `--filter`, `--stop-on-failure`, `--parallel` и т.д.)
- `artisan test`
- `vendor/bin/phpunit` / `./vendor/bin/phpunit`
- `pest` / `./vendor/bin/pest`
- Любые цепочки команд, вызовы через bash/sh или скрипты, запускающие тесты Laravel/PHPUnit/Pest.

### Правило поведения:
- Ни при каких условиях (валидация фиксов, просьба проверить код, проверка после правок) не запускать тестовые команды через терминал (`run_command`).
- Проверку тестов осуществлять исключительно статическим просмотром кода тестов.
- Если требуется выполнить тесты, явно оставлять эту команду на усмотрение пользователя для ручного запуска.
